# Anti-Codex 真人口型短片自主长任务总目标

你是这个全新工程的唯一执行者。请先检查当前工程和可用工具，调用 `update_plan` 自己制定覆盖完整交付的计划，然后连续执行、更新计划、诊断失败、返工并复验；不要等待主机逐步安排，也不要把计划、某个中间阶段或文字报告当作完成。

总目标：从零独立完成一支 45 至 60 秒、可发布的竖屏真人中文短片。题材、人物关系、故事或带货创意、脚本、分镜、素材方案、制作路线和内部阶段均由你自主决定。最终主片必须是 1080x1920、连续现实世界真人动态画面，至少一名真人在画面中清晰说出完整中文台词，语音与可见口型可核验同步；必须同时具有可懂对白、背景音乐、准确中文字幕以及完整故事闭环或带货闭环。动画、3D、数字人、图片轮播、PPT 朗读、联系人表或只有文字说明都不算成片。

最终工程必须包含可直接播放的主片、发布版本、封面、字幕文件、脚本与分镜、素材来源及授权/许可记录、可重复构建资料、机器可读的媒体质量与口型同步证据、全部交付文件的大小和 SHA-256 清单，以及整理完整的发布包。你必须用真实工具重新打开并验证最终媒体，至少检查解码、分辨率、时长、音视频流、黑场、静音、对白可懂度、字幕时间轴、音乐与对白平衡、响度和非重叠对白窗口的口型同步；任何硬性指标失败都要自行定位原因、修改或重做并再次验证。

所有本任务成果只写入当前工程目录。不得创建盘符映射、挂载点、计划任务、开机启动项或其他系统持久化；不得关闭、重启或修改 Codex、Anti-Codex、原生 Codex及其他用户应用；不得读取或输出密钥。遇到普通工具失败、素材失败、质量不合格或已有脚本错误时继续自主修复。只有提供方明确返回额度/服务错误，或操作确实需要用户批准的系统级权限时，才允许暂停并如实说明；否则只要计划仍有未完成项就必须继续。

完成全部制作与复验后，把机器可读的成果事实写入 `evidence/autonomous-video-deliverable.json`，其 schema 必须是 `anticodex-autonomous-video-deliverable-facts-v1`。顶层只使用 `schema`、`generatedAtUtc`、`artifacts`、`mainVideo`、`releaseVideos`、`subtitle`、`audio`、`lipSync`、`mediaQa`、`package`；`artifacts` 每项只写 `role` 和 `path`，`package` 只写 `manifestPath`，不要把该事实文件自身列入 `artifacts`。该文件只列交付文件的角色与路径，以及主片、三个发布版本、字幕、音频、口型窗口、媒体 QA 和校验清单的实际测量结果；每个交付文件的 basename 必须唯一，最终校验工具输出必须明确列出每个 `artifacts` 路径。不得填写或猜测 task、taskId、turnId、cwd、prompt、provider、model、component、releaseBinding、rollout 等任务、路由或发布元数据，也不得把自报哈希或大小当作验收结果。系统会从原生任务记录和签名回执独立推导这些元数据，并重新读取全部文件计算大小与 SHA-256；任何缺项或不一致都会失败。
